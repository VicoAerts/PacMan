\doxysubsection{Detailed Description}
Gameplay state for a single level. 

Creates a new World when entered, keeps it alive while the level is active, and transitions to other states (pause, victory, game over) via the \doxylink{classview_1_1state_1_1StateManager}{State\+Manager}.
