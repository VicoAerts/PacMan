\doxysubsection{Detailed Description}
\doxylink{classview_1_1state_1_1StateManager}{State\+Manager} class that manages different game states using a stack. 

The \doxylink{classview_1_1state_1_1StateManager}{State\+Manager} allows pushing, popping, and switching between different states, such as menu, gameplay, paused, and gameover states.
