\doxysubsection{Detailed Description}
Abstract base class for all game entities. 

Inherits from \doxylink{classmodel_1_1Subject}{Subject} to support the \doxylink{classmodel_1_1Observer}{Observer} pattern. This class belongs to the game logic layer and contains no rendering code.
